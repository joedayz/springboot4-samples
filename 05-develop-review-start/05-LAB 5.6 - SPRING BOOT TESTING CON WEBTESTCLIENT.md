## Objetivo

Este documento explica cómo testear la API REST del proyecto `develop-review` usando **WebTestClient**, la herramienta de testing nativa de Spring Boot 4, como alternativa a RestAssured.

## ¿Por qué WebTestClient?

| Característica | RestAssured | WebTestClient |
|---|---|---|
| Dependencia externa | Sí (`io.rest-assured`) | **No** (viene con Spring) |
| 100% Spring Boot | No | **Sí** |
| API fluida | Sí | **Sí (más moderna)** |
| Servidor HTTP real | Sí | Sí (con `RANDOM_PORT`) |
| Soporte reactivo | No | **Sí** |
| Validación JSON | JsonPath (Hamcrest) | **JsonPath (nativo)** |
| Groovy como transitividad | Sí | **No** |

**Ventajas de WebTestClient:**
- No requiere dependencias externas (solo `spring-boot-starter-webflux` en test scope)
- Es la herramienta recomendada por el equipo de Spring
- API consistente tanto para aplicaciones MVC como WebFlux
- Sin dependencia transitiva a Groovy (que causa problemas con Java 21+)

## Dependencia necesaria

Para usar `WebTestClient` en una aplicación Spring MVC (no WebFlux), se necesita agregar `spring-boot-starter-webflux` como dependencia de **test**:

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-webflux</artifactId>
    <scope>test</scope>
</dependency>
```

**NOTA:** Al agregar `webflux` en scope `test`, no afecta la aplicación en producción. Spring Boot sigue usando Spring MVC (servlet) porque `spring-boot-starter-web` tiene prioridad.

## Estructura del Test

### Anotaciones de la clase

```java
@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
@DirtiesContext(classMode = DirtiesContext.ClassMode.BEFORE_CLASS)
@TestMethodOrder(MethodOrderer.OrderAnnotation.class)
public class SpeakerControllerWebClientTest {

    @LocalServerPort
    int port;

    WebTestClient webTestClient;

    @BeforeEach
    void setUp() {
        webTestClient = WebTestClient.bindToServer()
                .baseUrl("http://localhost:" + port)
                .build();
    }
}
```

**Explicación:**
- `@SpringBootTest(webEnvironment = RANDOM_PORT)` - Levanta un servidor HTTP real en un puerto aleatorio
- `@DirtiesContext(classMode = BEFORE_CLASS)` - Reinicia el contexto Spring antes de esta clase de tests (para tener una BD limpia si se ejecuta junto con otros tests)
- `@TestMethodOrder(OrderAnnotation.class)` - Ejecuta los tests en el orden definido por `@Order`
- `WebTestClient.bindToServer()` - Crea un cliente HTTP que se conecta al servidor real

## Comparación lado a lado: RestAssured vs WebTestClient

### GET - Listar (verificar lista vacía)

**RestAssured:**
```java
given()
    .when()
    .get("/speakers")
    .then()
    .statusCode(200)
    .body("$.size()", is(0));
```

**WebTestClient:**
```java
webTestClient.get().uri("/speakers")
    .exchange()
    .expectStatus().isOk()
    .expectBody()
    .jsonPath("$.length()").isEqualTo(0);
```

### POST - Crear recurso

**RestAssured:**
```java
given()
    .body(json)
    .contentType("application/json")
    .when()
    .post("/speakers")
    .then()
    .statusCode(201)
    .header("location", startsWith("http://"))
    .header("id", Integer::parseInt, greaterThanOrEqualTo(0));
```

**WebTestClient:**
```java
webTestClient.post().uri("/speakers")
    .contentType(MediaType.APPLICATION_JSON)
    .bodyValue(json)
    .exchange()
    .expectStatus().isCreated()
    .expectHeader().exists("location")
    .expectHeader().valueMatches("location", "http://.*")
    .expectHeader().exists("id");
```

### GET - Verificar contenido JSON

**RestAssured:**
```java
given()
    .when()
    .get("/speakers")
    .then()
    .statusCode(200)
    .body(
        "$.size()", is(2),
        "[0].name", is("Pablo"),
        "[1].name", is("Noelia")
    );
```

**WebTestClient:**
```java
webTestClient.get().uri("/speakers")
    .exchange()
    .expectStatus().isOk()
    .expectBody()
    .jsonPath("$.length()").isEqualTo(2)
    .jsonPath("$[0].name").isEqualTo("Pablo")
    .jsonPath("$[1].name").isEqualTo("Noelia");
```

### GET - Con query params

**RestAssured:**
```java
given()
    .when()
    .get("/speakers?sortBy=name")
    .then()
    .statusCode(200)
    .body(
        "[0].name", is("Noelia"),
        "[1].name", is("Pablo")
    );
```

**WebTestClient:**
```java
webTestClient.get().uri("/speakers?sortBy=name")
    .exchange()
    .expectStatus().isOk()
    .expectBody()
    .jsonPath("$[0].name").isEqualTo("Noelia")
    .jsonPath("$[1].name").isEqualTo("Pablo");
```

### DELETE - Recurso existente (204)

**RestAssured:**
```java
given()
    .when()
    .delete("/speakers/1")
    .then()
    .statusCode(204);
```

**WebTestClient:**
```java
webTestClient.delete().uri("/speakers/1")
    .exchange()
    .expectStatus().isNoContent();
```

### DELETE - Recurso no existente (404)

**RestAssured:**
```java
given()
    .when()
    .delete("/speakers/123456")
    .then()
    .statusCode(404);
```

**WebTestClient:**
```java
webTestClient.delete().uri("/speakers/123456")
    .exchange()
    .expectStatus().isNotFound();
```

## Test completo con WebTestClient

**Archivo:** `src/test/java/com/bcp/training/speaker/SpeakerControllerWebClientTest.java`

```java
package com.bcp.training.speaker;

import org.junit.jupiter.api.*;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.boot.test.web.server.LocalServerPort;
import org.springframework.http.MediaType;
import org.springframework.test.annotation.DirtiesContext;
import org.springframework.test.web.reactive.server.WebTestClient;

@SpringBootTest(webEnvironment = SpringBootTest.WebEnvironment.RANDOM_PORT)
@DirtiesContext(classMode = DirtiesContext.ClassMode.BEFORE_CLASS)
@TestMethodOrder(MethodOrderer.OrderAnnotation.class)
public class SpeakerControllerWebClientTest {

    @LocalServerPort
    int port;

    WebTestClient webTestClient;

    @BeforeEach
    void setUp() {
        webTestClient = WebTestClient.bindToServer()
                .baseUrl("http://localhost:" + port)
                .build();
    }

    private final String[] samples = {
        "{\"name\":\"Pablo\",\"organization\":\"Red Hat\",\"talks\":[{\"title\":\"Lorem ipsum dolor sit amet\",\"duration\":15}]}",
        "{\"name\":\"Noelia\",\"organization\":\"Red Hat\",\"talks\":[{\"title\":\"Consectetur adipiscing elit\",\"duration\":20}]}",
    };

    @Test
    @Order(1)
    public void initialListOfSpeakersIsEmpty() {
        webTestClient.get().uri("/speakers")
                .exchange()
                .expectStatus().isOk()
                .expectBody()
                .jsonPath("$.length()").isEqualTo(0);
    }

    @Test
    @Order(2)
    public void createSpeakers() {
        webTestClient.post().uri("/speakers")
                .contentType(MediaType.APPLICATION_JSON)
                .bodyValue(samples[0])
                .exchange()
                .expectStatus().isCreated()
                .expectHeader().exists("location")
                .expectHeader().valueMatches("location", "http://.*")
                .expectHeader().exists("id");

        webTestClient.post().uri("/speakers")
                .contentType(MediaType.APPLICATION_JSON)
                .bodyValue(samples[1])
                .exchange()
                .expectStatus().isCreated()
                .expectHeader().exists("location")
                .expectHeader().valueMatches("location", "http://.*")
                .expectHeader().exists("id");
    }

    @Test
    @Order(3)
    public void sortingSpeakersByDefault() {
        webTestClient.get().uri("/speakers")
                .exchange()
                .expectStatus().isOk()
                .expectBody()
                .jsonPath("$.length()").isEqualTo(2)
                .jsonPath("$[0].name").isEqualTo("Pablo")
                .jsonPath("$[1].name").isEqualTo("Noelia");
    }

    @Test
    @Order(3)
    public void sortingSpeakersByName() {
        webTestClient.get().uri("/speakers?sortBy=name")
                .exchange()
                .expectStatus().isOk()
                .expectBody()
                .jsonPath("$.length()").isEqualTo(2)
                .jsonPath("$[0].name").isEqualTo("Noelia")
                .jsonPath("$[1].name").isEqualTo("Pablo");
    }

    @Test
    @Order(3)
    public void pageSizeLimitsTheResultsCollection() {
        webTestClient.get().uri("/speakers?pageSize=1")
                .exchange()
                .expectStatus().isOk()
                .expectBody()
                .jsonPath("$.length()").isEqualTo(1)
                .jsonPath("$[0].name").isEqualTo("Pablo");
    }

    @Test
    @Order(3)
    public void pageIndexLimitsTheResultsCollection() {
        webTestClient.get().uri("/speakers?pageSize=1&pageIndex=1")
                .exchange()
                .expectStatus().isOk()
                .expectBody()
                .jsonPath("$.length()").isEqualTo(1)
                .jsonPath("$[0].name").isEqualTo("Noelia");
    }

    @Test
    @Order(4)
    public void deleteNonExistingSpeakerReturns404() {
        webTestClient.delete().uri("/speakers/123456")
                .exchange()
                .expectStatus().isNotFound();
    }

    @Test
    @Order(4)
    public void deleteExistingSpeakerReturns204AndRemovesItFromPersistenceLayer() {
        webTestClient.delete().uri("/speakers/1")
                .exchange()
                .expectStatus().isNoContent();

        webTestClient.get().uri("/speakers")
                .exchange()
                .expectStatus().isOk()
                .expectBody()
                .jsonPath("$.length()").isEqualTo(1)
                .jsonPath("$[0].name").isEqualTo("Noelia");
    }
}
```

## Métodos útiles de WebTestClient

### Verificar status HTTP

```java
.expectStatus().isOk()              // 200
.expectStatus().isCreated()          // 201
.expectStatus().isNoContent()        // 204
.expectStatus().isNotFound()         // 404
.expectStatus().isBadRequest()       // 400
.expectStatus().is5xxServerError()   // 5xx
.expectStatus().isEqualTo(418)       // Código específico
```

### Verificar headers

```java
.expectHeader().exists("location")
.expectHeader().doesNotExist("X-Custom")
.expectHeader().valueEquals("Content-Type", "application/json")
.expectHeader().valueMatches("location", "http://.*")
```

### Verificar body con JsonPath

```java
.expectBody()
    .jsonPath("$.length()").isEqualTo(2)
    .jsonPath("$[0].name").isEqualTo("Pablo")
    .jsonPath("$[0].talks[0].title").isEqualTo("Lorem ipsum")
    .jsonPath("$[0].id").isNumber()
    .jsonPath("$[0].name").isNotEmpty()
```

### Verificar body como tipo Java

```java
.expectBodyList(Speaker.class).hasSize(2)
.expectBody(Speaker.class).value(speaker -> {
    assertThat(speaker.getName()).isEqualTo("Pablo");
})
```

### Enviar body

```java
// Como String JSON
.bodyValue("{\"name\":\"Pablo\"}")

// Como objeto Java
Speaker speaker = new Speaker();
speaker.setName("Pablo");
.bodyValue(speaker)
```

## Cuándo usar cada herramienta

| Escenario | Recomendación |
|---|---|
| Proyecto nuevo Spring Boot 4 | **WebTestClient** |
| Migración desde Quarkus (ya tiene RestAssured) | **RestAssured** (mantener consistencia) |
| Tests que necesitan ser idénticos en Quarkus y Spring | **RestAssured** |
| Aplicaciones reactivas (WebFlux) | **WebTestClient** |
| Minimizar dependencias externas | **WebTestClient** |
| Compatibilidad con Java 21+ sin problemas | **WebTestClient** |

## Troubleshooting

### Error: "WebTestClient bean not found"

**Solución:** Verifica que `spring-boot-starter-webflux` esté como dependencia de test en el `pom.xml`

### Error: "Tests fail with stale data"

**Solución:** Agrega `@DirtiesContext(classMode = DirtiesContext.ClassMode.BEFORE_CLASS)` a la clase de test para obtener un contexto limpio

### Error: "Could not resolve placeholder"

**Solución:** Verifica que usas `@SpringBootTest(webEnvironment = RANDOM_PORT)` y `@LocalServerPort`
